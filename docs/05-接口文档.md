**项目名称**：校园闲置物品交易小程序
**文档版本**：V1.0

**Base URL**：`http://localhost:3000`

---

## 1. 通用约定

### 1.1 请求头

```http
Content-Type: application/json
Authorization: Bearer <token>     # 除标注"公开"外均需携带
```

### 1.2 统一响应

```jsonc
// 成功
{ "code": 200, "message": "说明（可选）", ...业务字段 }
// 失败
{ "code": 400, "message": "面向用户的中文提示" }
```

### 1.3 状态码语义

| 状态码 | 含义 | 典型场景 |
| --- | --- | --- |
| 200 | 成功 | 查询、更新、动作 |
| 201 | 已创建 | 注册、发布、下单、发消息、上传 |
| 400 | 参数/业务校验失败 | 字段非法、状态机不允许、重复下单 |
| 401 | 未登录或凭证失效 | 无 token、token 伪造/过期、密码错误 |
| 403 | 无权限 | 操作他人资源、非订单参与方 |
| 404 | 资源不存在 | 商品已下架、订单/用户不存在 |
| 409 | 冲突 | 学号已注册 |
| 413 | 载荷过大 | 图片 >4MB、JSON >6MB |
| 500 | 服务内部错误 | 未预期异常 |

### 1.4 分页参数与返回

- 请求：`?page=1&pageSize=12`（pageSize 上限 30）
- 返回：`{ list, total, page, pageSize, hasMore }`

### 1.5 枚举速查

- 分类：数码电器 / 教材书籍 / 生活用品 / 服饰鞋包 / 运动户外 / 美妆个护 / 乐器手办 / 其他
- 成色：全新 / 99新 / 95新 / 9成新 / 8成新
- 商品状态：`on_sale` / `trading` / `sold` / `offline`
- 订单状态：`pending` / `confirmed` / `completed` / `cancelled`

## 2. 通用模块

### 2.1 GET /api/health — 健康检查（公开）

```jsonc
// 200
{ "code": 200, "status": "ok", "time": "2026-09-29T08:00:00.000Z", "service": "campus-swap-api" }
```

### 2.2 GET /api/unread — 未读消息总数

```jsonc
// 200  { "code": 200, "count": 3 }
// 401  { "code": 401, "message": "请先登录后再操作" }
```

### 2.3 POST /api/upload — 图片上传

请求：

```jsonc
{ "dataUrl": "data:image/png;base64,iVBORw0KGgo..." }
```

| 规则 | 值 |
| --- | --- |
| MIME 白名单 | png / jpeg / webp / gif |
| 大小上限 | 4MB（解码后，超出 413） |
| 返回 | 201 `{ code:201, message:"上传成功", url:"/uploads/1696...a3f2.png" }` |

错误：`400 仅支持 PNG / JPG / WebP / GIF 图片`、`400 图片内容为空`。

## 3. 认证与用户模块

### 3.1 POST /api/auth/register — 注册（公开）

```jsonc
// 请求
{ "studentId": "20230105", "nickname": "新同学", "password": "123456",
  "college": "计算机学院", "phone": "13800000000" }   // college/phone 可选
```

| 字段 | 规则 |
| --- | --- |
| studentId | 必填，`^[A-Za-z0-9]{4,20}$`，唯一 |
| nickname | 必填，2-16 字 |
| password | 必填，6-32 字 |
| phone | 可选，`^[0-9\- ]{6,20}$` |

```jsonc
// 201
{ "code": 201, "message": "注册成功", "token": "payload.signature",
  "user": { "id":5, "studentId":"20230105", "nickname":"新同学", "avatar":"", "college":"计算机学院", "phone":"...", "bio":"", "createdAt":"..." } }
// 400 学号只能包含 4-20 位字母或数字 / 409 该学号已注册，请直接登录
```

### 3.2 POST /api/auth/login — 登录（公开）

```jsonc
// 请求 { "studentId": "20230101", "password": "123456" }
// 200  { "code":200, "message":"登录成功", "token":"...", "user":{...} }
// 401  { "code":401, "message":"学号或密码错误" }   // 不区分"用户不存在/密码错"
```

### 3.3 GET /api/me — 当前用户

```jsonc
// 200 { "code":200, "user": { ...publicUser } }   // 永不含 password_hash
// 401 未登录
```

### 3.4 PUT /api/me — 修改资料

```jsonc
// 请求（全部可选，缺省保留原值）
{ "nickname":"张小满", "college":"计算机学院", "phone":"13800001111", "bio":"大三学姐", "avatar":"/img/logo.svg" }
// 200 { "code":200, "message":"资料已更新", "user":{...} }
```

### 3.5 PUT /api/me/password — 修改密码

```jsonc
{ "oldPassword": "123456", "newPassword": "654321" }
// 200 { "code":200, "message":"密码已修改，请重新登录" }
// 401 原密码错误   400 新密码 6-32 位
```

### 3.6 GET /api/stats — 个人统计

```jsonc
// 200
{ "code":200, "stats": { "on_sale":3, "sold":2, "bought":4, "favorites":5, "revenue":668.5, "pending":1 } }
```

### 3.7 GET /api/users/:id — 用户公开主页（可选鉴权）

```jsonc
// 200
{ "code":200,
  "user": { ...publicUser, "rating":4.9, "ratingCount":12 },
  "items": [ { ...商品DTO }, ... ] }     // 该用户 on_sale/sold 商品，最多 30
// 404 用户不存在
```

## 4. 商品模块

### 4.1 GET /api/categories — 分类目录（公开）

```jsonc
// 200
{ "code":200,
  "categories": [ { "name":"数码电器", "count":3 }, ... 八个分类 ],
  "conditions": ["全新","99新","95新","9成新","8成新"] }
```

### 4.2 GET /api/items — 商品列表/检索（可选鉴权）

| 查询参数 | 说明 |
| --- | --- |
| keyword | 标题/描述模糊匹配，≤40 字 |
| category / condition | 精确过滤 |
| minPrice / maxPrice | 价格区间 |
| sort | `new`(默认) / `price_asc` / `price_desc` / `hot` |
| page / pageSize | 分页，pageSize≤30 |
| mine=1 + status | 仅登录：我的商品，status 可 `all`/`on_sale`/`sold`/`offline` |
| sellerId | 某卖家的在售+已售商品 |

```jsonc
// 200
{ "code":200, "total":12, "page":1, "pageSize":12, "hasMore":false,
  "list": [ { "id":1, "title":"九成新索尼降噪耳机", "price":429, "originalPrice":1299,
              "category":"数码电器", "condition":"9成新", "images":["/img/item-headphone.svg"],
              "spot":"三食堂门口", "status":"on_sale", "viewCount":56, "favCount":3,
              "isFavorite":false, "createdAt":"...",
              "seller": { "id":1, "nickname":"张小满", "avatar":"", "college":"计算机学院",
                          "rating":4.9, "ratingCount":12 } } ] }
```

### 4.3 GET /api/items/:id — 商品详情（可选鉴权）

```jsonc
// 200
{ "code":200, "item": { ...同上DTO }, "seller": { ...同上seller },
  "reviews": [ { "rating":5, "content":"很靠谱", "createdAt":"...", "buyer":{ "nickname":"王大锤", "avatar":"" } } ],
  "activeOrder": { "id":4, "status":"confirmed" },   // 当前用户进行中订单，无则 null
  "isOwner": false }
// 404 商品不存在或已下架（offline 对非卖家）
```

副作用：`view_count += 1`。

### 4.4 POST /api/items — 发布商品

```jsonc
{ "title":"九成新台灯", "category":"生活用品", "condition":"99新",
  "price":30, "originalPrice":80, "description":"自用护眼灯", "spot":"一食堂门口",
  "images":["/uploads/xxx.png"] }
```

| 字段 | 规则 |
| --- | --- |
| title | 2-30 字 |
| category / condition | 枚举白名单 |
| price | 0.01-99999；originalPrice ≥ price（否则 400） |
| images | 1-6 张；地址白名单 `/uploads/` `/img/` `data:image/` `http(s)://`；单张 ≤500KB |

```jsonc
// 201 { "code":201, "message":"发布成功", "item":{ ...商品DTO, "status":"on_sale" } }
// 400 请至少上传 1 张商品图片 / 原价不能低于售价 / 分类取值不合法
```

### 4.5 PUT /api/items/:id — 修改商品（仅卖家）

所有字段可选，缺省保留原值；可附 `status` 切换 `on_sale|offline|sold`。

```jsonc
{ "title":"改后的标题", "price":25, "status":"on_sale" }
// 200 { "code":200, "message":"商品已更新", "item":{...} }
// 403 无权操作他人的商品   404 商品不存在或已下架
```

### 4.6 DELETE /api/items/:id — 下架（仅卖家）

```jsonc
// 200 { "code":200, "message":"商品已下架" }
// 400 该商品存在进行中的订单，请先处理订单再下架
// 403 非卖家
```

### 4.7 /api/items/:id/favorite — 收藏/取消

```
POST   → 200 { "code":200, "favorited":true,  "favCount":4 }
DELETE → 200 { "code":200, "favorited":false, "favCount":3 }
// 404 商品不存在   401 未登录（重复收藏幂等，仍返回 200）
```

### 4.8 GET /api/favorites — 我的收藏

分页返回商品 DTO 数组，`fav_flag` 恒为 1，已下架商品被过滤。

```jsonc
// 200 { "code":200, "list":[...], "total":5, "page":1, "pageSize":20, "hasMore":false }
```

## 5. 订单模块

### 5.1 POST /api/orders — 下单

```jsonc
{ "itemId": 3, "spot": "二食堂门口", "note": "晚自习后见" }   // spot/note 可选
```

```jsonc
// 201
{ "code":201, "message":"下单成功，等待卖家确认",
  "order": { "id":4, "status":"pending", "statusText":"待卖家确认", "price":66,
             "role":"buyer", "item":{...}, "buyer":{...}, "seller":{...},
             "reviewed":false, "review":null, "createdAt":"...", "updatedAt":"..." } }
```

错误码矩阵：

| 场景 | 状态码 | message |
| --- | --- | --- |
| 商品不存在/已下架 | 404 | 商品不存在或已下架 |
| 买自己的商品 | 400 | 不能购买自己发布的商品 |
| 已被他人下单（trading/sold） | 400 | 该商品已被其他同学下单，请看看别的吧 |
| 已有进行中订单 | 400 | 你已有该商品的进行中订单 |

副作用：商品 `on_sale → trading`。

### 5.2 GET /api/orders — 订单列表

| 参数 | 说明 |
| --- | --- |
| role | `buyer`(默认) / `seller` |
| status | `all`(默认) / pending / confirmed / completed / cancelled |
| page / pageSize | pageSize≤30 |

```jsonc
// 200
{ "code":200, "list":[ { ...orderDTO } ], "total":4, "page":1, "pageSize":10, "hasMore":false,
  "statusMap": { "pending":"待卖家确认", "confirmed":"待当面交易", "completed":"已完成", "cancelled":"已取消" } }
```

`orderDTO.role` 表示"我在该订单中的角色"（buyer/seller）。

### 5.3 GET /api/orders/:id — 订单详情

```jsonc
// 200 { "code":200, "order":{ ...orderDTO }, "statusMap":{...} }
// 404 订单不存在   403 无权查看该订单（非参与方）
```

### 5.4 POST /api/orders/:id/status — 状态流转

```jsonc
{ "status": "confirmed" }   // confirmed | completed | cancelled
```

| 迁移 | 允许角色 | 错误 |
| --- | --- | --- |
| pending → confirmed | 仅卖家 | 买家发起 403"该操作只能由卖家发起" |
| confirmed → completed | 仅买家 | 卖家发起 403 |
| pending/confirmed → cancelled | 买卖双方 | 非参与方 403 |
| 终态再流转 / 未确认先完成 | — | 400 "订单当前状态「已完成」不能变更为「已取消」" |

```jsonc
// 200 { "code":200, "message":"订单已完成", "order":{ ...status:"completed" } }
```

副作用：`cancelled` → 商品恢复 `on_sale`；`completed` → 商品置 `sold`。

### 5.5 POST /api/orders/:id/review — 买家评价

```jsonc
{ "rating": 5, "content": "卖家很靠谱，东西和描述一致" }   // content 可选 ≤120 字
```

| 规则 | 结果 |
| --- | --- |
| 非买家 | 403 只有买家可以评价 |
| 订单未完成 | 400 订单完成后才能评价 |
| 已评价过 | 400 该订单已评价（`order_id` UNIQUE 双保险） |
| rating 非 1-5 整数 | 400 |

```jsonc
// 200 { "code":200, "message":"评价已提交", "order":{ ...,"reviewed":true,"review":{...} } }
```

### 5.6 GET /api/reviews — 我收到的评价

```jsonc
// 200
{ "code":200, "list":[ { "id":1, "rating":5, "content":"靠谱", "createdAt":"...",
                         "itemTitle":"索尼耳机", "buyer":{ "nickname":"王大锤", "avatar":"" } } ] }
```

## 6. 消息模块

### 6.1 POST /api/conversations — 发起/命中会话

```jsonc
{ "itemId": 3 }
// 200 { "code":200, "conversation":{ ...convBrief } }    // 已存在则返回同一会话（幂等）
// 400 这是你发布的商品，无需向自己发起咨询   404 商品不存在或已下架
```

`convBrief` 结构：

```jsonc
{ "id":2, "itemId":3, "item":{ "id":3, "title":"...", "image":"...", "price":66, "status":"on_sale" },
  "peer":{ "id":1, "nickname":"张小满", "avatar":"" },
  "lastMessage":"在的，随时交易", "lastTime":"...", "createdAt":"...",
  "unread":1, "role":"buyer" }
```

### 6.2 GET /api/conversations — 会话列表

```jsonc
// 200 { "code":200, "list":[ ...convBrief 按 lastTime 倒序 ], "totalUnread":3 }
```

### 6.3 GET /api/conversations/:id/messages — 聊天记录

| 参数 | 说明 |
| --- | --- |
| afterId | 增量游标：只返回 id > afterId 的消息（升序） |
| limit | 默认 50，上限 100 |

```jsonc
// 200
{ "code":200, "conversation":{ ...convBrief },
  "list":[ { "id":10, "content":"同学你好", "kind":"text", "createdAt":"...",
             "senderId":5, "fromMe":true, "isRead":false } ] }
// 403 无权访问该会话   404 会话不存在
```

### 6.4 POST /api/conversations/:id/messages — 发送消息

```jsonc
{ "content": "同学你好，还在吗？" }     // 1-500 字，空白内容 400
// 201 { "code":201, "message":{ "id":11, "content":"...", "kind":"text", "createdAt":"...",
//                              "senderId":5, "fromMe":true, "isRead":false } }
```

副作用：更新会话 `last_message`（截断 60 字）与 `last_time`。

### 6.5 POST /api/conversations/:id/read — 已读回执

```jsonc
// 200 { "code":200, "message":"已读" }    // 对方发来的消息全部 is_read=1
```

## 7. 鉴权失败统一示例

```jsonc
// 401（无 token / token 伪造或过期 / 修改密码接口原密码错）
{ "code": 401, "message": "请先登录后再操作" }
```

Token 有效期 7 天，前端 401 时清除本地会话并跳转 `#/login`。
