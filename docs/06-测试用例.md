# 测试用例
**项目名称**：校园闲置物品交易小程序
**文档版本**：V1.0
**编写日期**：2026-09-29
**测试框架**：`node:test`（Node 内置）+ `node:assert`
**执行命令**：`npm test` → `node --test tests/`

---

## 1. 测试策略

| 层次 | 内容 | 工具 | 状态 |
| --- | --- | --- | --- |
| 接口集成测试 | 31 个 API 覆盖认证/商品/订单状态机/消息/权限/校验/分页 | `tests/api.test.js` | ✅ 17/17 通过 |
| 浏览器端到端 | 登录→浏览→搜索→发布→下单→确认→收货→评价→私信全流程 | 浏览器手动执行 | ✅ 已通过 |
| 静态检查 | Node 语法校验 `node --check` | CLI | ✅ |

**测试环境隔离设计**：

1. 启动前设置 `process.env.DB_FILE` 指向 `os.tmpdir()` 下的独立库，**不污染演示数据**；
2. `app.listen(0)` 随机端口，避免端口冲突；
3. 固定测试账号（学号带 `Date.now()` 时间戳前缀），可重复执行不撞唯一约束；
4. 结束后关闭连接并删除临时库文件。
