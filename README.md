# 校园闲置物品交易小程序

> 面向在校学生的二手闲置交易 Web 应用（仿小程序交互），包含**商品发布、多条件检索、收藏、下单交易、订单状态机、买卖家互评、即时私信**等完整业务闭环。
> 前后端分离、分层架构、零第三方运行时依赖，附全套软件工程文档与自动化测试。

## 一、快速开始

### 环境要求

| 依赖 | 版本 | 说明 |
| --- | --- | --- |
| Node.js | **≥ 22.13** | 使用内置 `node:sqlite`、`node:test`，**无需 `npm install`** |
| 浏览器 | Chrome / Edge 等现代浏览器 | 前端无构建步骤 |

### 三条命令

```bash
# 1. （可选）生成占位图片资源
node tools/gen-images.js

# 2. 初始化演示数据（已有数据会自动跳过；加 --reset 可清空重建）
node server/seed.js

# 3. 启动服务
npm start          # 或 node server/index.js
```

打开浏览器访问 **http://localhost:3000** 即可。

Windows 用户也可以直接双击 **`启动.bat`**。

### 运行测试

```bash
npm test           # 17 个集成用例，覆盖认证/商品/订单状态机/消息/权限/校验/分页
```

## 四、技术要点

- **零第三方依赖**：HTTP 服务、路由、静态资源、SQLite、口令散列、测试框架全部使用 Node 内置模块，`npm install` 都不需要，天然规避供应链风险。
- **分层架构**：`路由层(routes) → 业务校验(util) → 数据访问(db)`，前端 `路由(app) → 页面(views) → 组件(ui) → 接口(api)`，职责单向依赖。
- **订单状态机**：以「谁有权发起」+「当前状态允许的迁移」双约束，杜绝越权与非法流转（详见 `docs/03-详细设计说明书.md`）。
- **安全**：scrypt 加盐哈希 + `timingSafeEqual` 定时安全比较；HMAC-SHA256 签名 Token；所有越权路径显式校验资源归属；静态资源路径穿越防护；上传 MIME 白名单 + 体积上限。
- **可测试性**：数据库路径可注入（测试用临时库），HTTP 服务支持临时端口，测试与演示数据完全隔离。

## 六、常见问题

**1. 提示 `node:sqlite` 不可用？**
升级到 Node.js ≥ 22.13。Windows 可使用免安装 zip 版解压后加入 `PATH`。

**2. 端口被占用？**
`set PORT=3001 && node server/index.js`

**3. 想重置演示数据？**
`node server/seed.js --reset`

**4. 前端改了没生效？**
静态资源以 `Cache-Control: no-store` 下发，浏览器强刷新（Ctrl+F5）即可。

**5. 数据存在哪里？**
`data/campus-swap.db`（SQLite 单文件），删除该文件并重新 `seed` 即可重置。
